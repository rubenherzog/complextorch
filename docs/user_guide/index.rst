User guide
==========

This guide explains the mathematical and scientific conventions implemented by
ComplexTorch. It is organized by workflow rather than by module name so that the
left navigation remains useful while reading individual pages.

Use the :doc:`../api` reference for signatures, parameters, return types, and
source links. Use this guide for models, equations, assumptions, tensor
semantics, numerical choices, interpretation, and scientific limitations.

The guide is grounded in the implementation on the repository ``main`` branch.
When external software is mentioned, it is a parity/reference implementation;
the cited scientific literature remains the primary mathematical authority.
