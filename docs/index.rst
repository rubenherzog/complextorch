ComplexTorch
============

ComplexTorch is a Torch-first library for batched vector autoregressive and
linear state-space inference together with model-derived analytical complexity
measures.

This documentation is built directly from the repository. Public API pages are
linked to the package docstrings so that signatures and source documentation
remain synchronized with the code.
