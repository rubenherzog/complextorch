ComplexTorch
============

ComplexTorch is a Torch-first library for batched vector autoregressive and
linear state-space inference together with model-derived analytical complexity
measures.

This documentation separates learning-oriented material from the public API
reference. Use the scientific user guide to understand models, equations,
assumptions, tensor semantics, numerical choices, and interpretation; use the
API reference when you need signatures, parameters, return types, and source
links.
